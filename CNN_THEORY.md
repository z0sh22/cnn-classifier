# Теория CNN — Полная справка

## Что такое CNN

Свёрточная нейронная сеть (CNN) — это архитектура для работы с изображениями. Главная идея: не обрабатывать все пиксели сразу, а искать **локальные паттерны** маленькими фильтрами, которые скользят по изображению. Сеть сама учится какие фильтры нужны — ты не задаёшь «ищи уши», она разбирается сама через обучение.

Работа строится **иерархически** — от простого к сложному:

```
Слой 1 → края, цвета
Слой 2 → текстуры, углы
Слой 3 → части объектов (ухо, колесо)
Dense  → «это кошка»
```

## Conv2D — свёрточный слой

Фильтр размером `k×k` скользит по изображению и в каждой позиции считает **скалярное произведение** своих весов и патча изображения. Результат — одно число: насколько этот паттерн совпал с тем, что фильтр ищет. Таких фильтров много параллельно (32, 64, 128...) — каждый ищет своё.

Число обучаемых параметров одного Conv2D слоя:

```
params = (k × k × C_in + 1) × C_out
```

Где `C_in` — каналы входа, `C_out` — число фильтров, `+1` — bias.

**Параметры слоя:**

| Параметр | Что делает |
|---|---|
| `filters` | Сколько паттернов ищем параллельно |
| `kernel_size` | Размер окна (3×3 — стандарт) |
| `padding='same'` | Добавляет нули по краям, размер карты не меняется |
| `activation='relu'` | ReLU после свёртки: `max(0, x)` — гасит отрицательное |

```python
layers.Conv2D(32, (3, 3), activation="relu", padding="same")
#             ↑    ↑           ↑                ↑
#         фильтры  ядро    после свёртки    размер не меняется
```

## MaxPooling2D — слой подвыборки

Делит карту признаков на окна `p×p` (обычно 2×2) и берёт **максимальное** значение в каждом.

Почему максимум, а не среднее? Максимум сохраняет самый сильный сигнал («фильтр что-то нашёл здесь»), тогда как среднее его размывает:

```
┌──┬──┐
│3 │8 │  среднее = 3.5  ← сигнал потерян
│1 │2 │  максимум = 8   ← сигнал сохранён ✅
└──┴──┘
```

**Два ключевых эффекта:**

- **Сжатие** — 32×32 → 16×16, уменьшает число вычислений
- **Инвариантность к сдвигам** — кошачье ухо чуть левее/правее → MaxPool это сглаживает, сеть всё равно его видит

Параметров нет — только операция над данными.

```python
layers.MaxPooling2D((2, 2))
```

## Dropout — регуляризация

Во время обучения случайно **обнуляет долю нейронов** (например `rate=0.5` → 50%) на каждом шаге. При инференсе (предсказании) Dropout выключается — все нейроны активны.

```
Обучение:  [•][•][ ][ ][•][ ][•]  ← 50% выключены случайно
Инференс:  [•][•][•][•][•][•][•]  ← все активны
```

**Зачем нужен:**  
Без него сеть «запоминает» обучающие данные наизусть — train accuracy 99%, val accuracy 65%. Это **переобучение**. Dropout заставляет оставшиеся нейроны справляться без «выключенных коллег» → сеть учится устойчивым признакам, а не заучивает примеры.

> Обычно ставится **после Dense**, а не после Conv — Conv слои слабо склонны к переобучению из-за малого числа параметров.

```python
layers.Dropout(0.5)  # выключает 50% нейронов при обучении
```

## BatchNormalization — нормализация батчей

**Проблема:** после каждого слоя числа «уезжают» в разные диапазоны — одни нейроны выдают 0.001, другие 500. Оптимизатор теряется, обучение нестабильно.

BatchNorm нормализует активации внутри батча — делает среднее ≈ 0 и стандартное отклонение ≈ 1:

```
z_norm = (z - μ_batch) / sqrt(σ²_batch + ε)
```

Затем добавляет два **обучаемых параметра** γ (масштаб) и β (сдвиг) — сеть сама решает нужна ли ей нормализация:

```
y = γ · z_norm + β
```

**Эффекты на практике:**

| Без BatchNorm | С BatchNorm |
|---|---|
| Нужен маленький learning rate | Можно ставить в 5–10× больше |
| Обучение нестабильное | Стабильное, без скачков loss |
| 30 эпох чтобы сойтись | 10–15 эпох |
| Чувствительно к инициализации | Почти не зависит |

> Ставится **после Conv2D**, до или после ReLU — оба варианта работают.

```python
layers.Conv2D(64, (3, 3), activation="relu", padding="same"),
layers.BatchNormalization(),  # сразу после Conv
layers.MaxPooling2D((2, 2)),
```

## Dense + Softmax — классификатор

**Dense(N)** — полносвязный слой: каждый нейрон смотрит на **все** входы.  
Математически: `y = activation(W·x + b)`, где `W` — матрица весов которая обучается.

- `Dense(128, relu)` — промежуточный аналитик: берёт вектор признаков от Conv слоёв и учится выделять из него полезное для классификации
- `Dense(10, softmax)` — финальный ответ: 10 нейронов, по одному на класс

**Softmax** превращает числа в вероятности (сумма = 1.0):

```
softmax(z_i) = e^z_i / Σ e^z_j
```

```python
# Пример выхода softmax:
[0.02, 0.01, 0.87, 0.03, 0.01, 0.02, 0.01, 0.01, 0.01, 0.01]
  ✈️    🚗    🐱    🦌    🐶    🐸    🐴    🚢    🚛   ...
              ↑
          87% — кот!
```

## Полный пайплайн simple_cnn на CIFAR-10

```
Вход (32, 32, 3)           — 3072 числа, RGB изображение
    ↓
Conv2D(32, 3×3, relu)      → (32, 32, 32)  — 32 карты: края, цвета
    ↓
MaxPooling(2×2)            → (16, 16, 32)  — сжали вдвое
    ↓
Conv2D(64, 3×3, relu)      → (16, 16, 64)  — 64 карты: формы, части
    ↓
MaxPooling(2×2)            → (8,  8,  64)  — сжали вдвое
    ↓
Flatten                    → (4096,)       — развернули в вектор
    ↓
Dense(128, relu)           → (128,)        — финальный анализ
    ↓
Dropout(0.5)               → (128,)        — защита от переобучения
    ↓
Dense(10, softmax)         → (10,)         — вероятности классов
    ↓
argmax → "cat" (87%)
```

## Ключевые концепции одной строкой

| Термин | Суть |
|---|---|
| **Фильтр (ядро)** | Маленькая матрица весов, ищет один паттерн |
| **Карта признаков** | Результат прохода одного фильтра по изображению |
| **ReLU** | Функция активации: обнуляет отрицательное, оставляет положительное |
| **Padding=same** | Дополняет края нулями, чтобы размер не уменьшался |
| **Переобучение** | Сеть запомнила train, но плохо работает на новых данных |
| **Инвариантность** | Сеть узнаёт объект даже если он сдвинулся/повернулся |
| **Representation learning** | Сеть сама строит описание объекта, признаки не нужно задавать вручную |
| **Батч** | Пачка изображений (например 64 штуки), обрабатывается за один шаг |
| **Epoch** | Один полный проход по всему обучающему датасету |
